# 🛒 Full-Stack E-commerce Store

A modern, responsive E-commerce application built with **Next.js** and **Tailwind CSS**. This project features a complete shopping experience, including product browsing, categories, and a secure checkout flow.

## 🚀 Key Features
* **Dynamic Product Listing:** Fetching and displaying products from a REST API.
* **Shopping Cart:** Add, remove, and update products in the cart.
* **Authentication:** Secure user login and registration system.
* **Responsive Design:** Fully optimized for all screen sizes using Tailwind CSS.
* **Fast Performance:** Optimized images and server-side rendering with Next.js.

## 🛠️ Tech Stack
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
